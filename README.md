# InfoSec Wizard

Static GitHub Pages site for the InfoSec Wizard community: a centralized roadmap and resource room. Homepage and roadmap are live. Resources, Blogs, Labs, and CTFs are named, not built.

## Local

```bash
python3 -m http.server 4173
```

Open http://127.0.0.1:4173

## GitHub Pages

1. Push this repo.
2. Settings → Pages → Deploy from branch → `main` / root (`/`).
3. Keep paths relative (`css/site.css`, not `/css/site.css`) so project pages (`username.github.io/repo`) work.

## Swap the second operator

In `index.html`, the `#operators` section: name and bio. Photos are the default avatar at `assets/operators/avatar.svg`.
